# CLAUDE.md

Web map of a store network ("Mapa sklepów"). A Python server reads and writes an Excel/CSV file, and a
Leaflet page shows the stores, incidents (usterki) and regions. No build step, no npm.
**Deployed in Docker on an Ubuntu server, LAN-only**: viewing is open, editing needs one shared password.
Machine- and deployment-specific notes (server address, local paths) are in the git-ignored `CLAUDE.local.md`.

Git: https://github.com/theAbominableFox/store-map-remote (branch `main`). **Nothing private may be committed**:
`.gitignore` keeps all `*.xlsx`/`*.csv` (real store data), `dane/`, `kopie/`, `.env` and `CLAUDE.local.md` out; the only
committed xlsx is the made-up `przyklad/mapa_dane_przyklad.xlsx` (regenerate with `tools/make_example.py`). Keep real
store names, people, region codes, server addresses and user names out of code, docs and commit messages.
`.gitattributes` forces LF for `*.sh`/Dockerfile/yml and CRLF for `*.bat`.
Deploy = push to `main`, then `bash wdroz.sh` in the app folder on the server: it `git fetch` + fast-forwards via the
read-only deploy key `~/.ssh/mapa_sklepow_deploy` (`core.sshCommand`), refuses if tracked files were edited on the
server, then `docker compose up -d --build`. The script body is inside `main()` so the pull can replace the file while it runs.

## Run

```bash
python server.py przyklad/mapa_dane_przyklad.xlsx   # try it with made-up data (edits change that file – don't commit them)
python server.py mapa_dane.xlsx                     # local mode: localhost:8000, no password, opens a browser
python server.py <copy>.xlsx --port 8765 --no-browser   # for testing – always on a COPY of the data
MAPA_HASLO=test python server.py <copy>.xlsx --host 0.0.0.0 --port 8765 --no-browser   # network mode, as in Docker
docker compose up -d --build                        # on the server; settings in .env (see .env.example)
```

Config via env (CLI args win): `MAPA_DATA`, `MAPA_HOST` (default 127.0.0.1), `MAPA_PORT`, `MAPA_HASLO`,
`MAPA_TYLKO_LAN` (default 1 = 403 for non-private client IPs), `MAPA_KOPIE` (backups kept, default 30).
The server refuses to start on a non-loopback host without `MAPA_HASLO`.

`start.bat` (finds Python: `py -3` → `python` → `%LOCALAPPDATA%\Programs\Python\Python312`) and `install.bat`
(Python 3.12 via winget + `pip install --user -r requirements.txt`) are the user-facing launchers.
The only dependency is `openpyxl`.

## Layout

- `server.py` – stdlib `ThreadingHTTPServer` + openpyxl. Serves `static/` and a JSON API:
  `GET /api/data|/api/version|/api/auth|/api/xlsx|/api/geocode?q=`, `POST/PUT/DELETE /api/stores[/id]`,
  `/api/incidents[/id]`, `PUT /api/regions`, `POST /api/xlsx|/api/login|/api/logout`. (JSON export/import was removed
  on purpose – Excel download/upload replaces it.) Every request re-reads
  the whole file under `LOCK` and writes it back atomically (`.tmp` + `os.replace`).
- Auth: stateless signed cookie `mapa_sesja` (`<expiry>.<hmac>`, key derived from `MAPA_HASLO`, 30 days, HttpOnly,
  SameSite=Strict) + an Origin check on writes. All writes and `/api/geocode` need it; GETs of data/xlsx/export don't.
  `/api/data` returns `editor`/`login`; the front end toggles `body.editor` – elements with class `ed` are editor-only,
  `view-only` viewer-only. Failed logins sleep 1 s under a global lock.
- Branding: `GET /marka/logo|/marka/favicon` serve `<data dir>/marka/{logo,favicon}.{png,svg,jpg,webp,ico}` (env
  `MAPA_MARKA` overrides the folder), else the neutral `static/domyslne/*.svg`; `marka/nazwa.txt` → `brand` in
  `/api/data` → tab title "Mapa sklepów | <name>". Company logo/name never go into the repo (`marka/` is git-ignored).
- `backup(reason)` copies the data file to `<data dir>/kopie/` before an xlsx upload and prunes old ones.
- `Dockerfile` + `docker-compose.yml`: data on the `./dane:/data` bind mount (a directory, so `os.replace` works),
  runs as uid 1000, `TZ=Europe/Warsaw`. Port binding uses `MAPA_ADRES` because Docker bypasses ufw.
- `static/app.js` – the whole front end (vanilla JS, Leaflet 1.9.4 from unpkg). `static/style.css` – light/dark tokens.
- `static/granice.geojson` – national + voivodeship border lines, generated by `tools/build_borders.py`
  from ppatrzyk/polska-geojson `wojewodztwa-medium.geojson` (GUGiK data). Not part of the data file.
- `mapa_dane.xlsx` (git-ignored) – **the user's live data**. Never overwrite it without a backup and the user's OK;
  test on a copy, or on `przyklad/mapa_dane_przyklad.xlsx`.

## Data model (the xlsx file)

- Sheet 1 (`POSy`, read by position, not by name): stores. Column 0 = store name (used as the key).
  Columns found by regex: `adres`, `region`, `rodzaj|typ`. App columns: `Status` (`aktywny`/`pending` = "nowe otwarcie"),
  `Lat`, `Lng`, `ID` (8-hex uuid).
- `Incydenty`: `ID, POS, Priorytet, Komentarz, Status, Data zgłoszenia, Data zamknięcia, Data przewidywana` (optional `YYYY-MM-DD`).
  `POS` = store name; an incident **must** reference an existing store (server returns 400 otherwise).
  Priorities `niski/średni/wysoki`; statuses `nowa → w trakcie → naprawiona` (closing date is set by the server).
- `Regiony`: `Region, Kolor, Typ`. `Typ = "inne"` marks non-store locations (e.g. "Inne lokalizacje" – warehouses):
  they're on the map but excluded from the sklepów/nowe/franczyz stat tiles.
- `Rodzaj = "franczyza"` → hollow pin; otherwise filled. Pending → diamond pin. Stores with no region → `#4a4a47`.
- `normalize()` in server.py upgrades older files (otwarty/zamknięty, krytyczny, incident Lat/Lng, missing Typ) on load.
- Cascades handled in the server: renaming a store renames its incidents' `POS`; deleting a store deletes its incidents;
  renaming a region rewrites the `Region` column of its stores.
- CSV mode: `x.csv` + `x_incydenty.csv` + `x_regiony.csv` (`;`, UTF-8 with BOM).

## Conventions

- The UI and all data values are **Polish**; code comments are mixed PL/EN. Keep new UI text in Polish.
- Map styles (bottom-left picker, `localStorage "styl-mapy"`): `standard`, `muted`, `dark` (CSS filters on the OSM
  tile pane) and `darkgray` (Esri Dark Gray base + reference labels). Borders are red on light styles, white on dark ones.
- Marker stacking: `zIndexOffset` = 500 + 100 × top open-incident priority; `riseOnHover` with `riseOffset: 10000`.
- Trasa (button next to the magnifier): stop list of store IDs in `localStorage "trasa"` (per browser, not in the xlsx), drawn as
  straight lines; `googleLinks()` builds Google Maps links from coordinates only. No routing on the server (user decision).
- The page polls `/api/version` every 5 s and reloads when the file changes (edits made in Excel show up by themselves).

## Gotchas

- **Restart the server after editing `server.py`** – the user's running `start.bat` keeps the old code, which silently
  drops new columns on save. Changes to `static/` only need a browser refresh locally; in Docker both need
  `docker compose up -d --build` (code is baked into the image).
- Windows locks the xlsx while it's open in Excel → `PermissionError` → the API returns 409 with a message.
- `.bat` files must have **CRLF** line endings (the Write tool produces LF; convert with `sed -i 's/$/\r/'`), or cmd breaks labels.
- Run Python with `-I` when processing downloaded files; keep downloads in their own scratch folder.
- Nominatim geocoding (proxied by the server): max 1 req/s, generic User-Agent, `countrycodes=pl,de`.
- CARTO basemaps now need an API key – don't use them.
